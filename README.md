# 🧩 Mini ERP - Gestão Empresarial Integrada

Este é um sistema **ERP (Enterprise Resource Planning)** desenvolvido com **Streamlit**. Ele permite gerenciar **produtos**, **clientes**, **vendas**, **finanças** e visualizar **métricas em um dashboard** integrado.

---

## 🚀 Funcionalidades

### 📦 Gestão de Produtos
- Cadastro de produtos com:
  - Nome
  - Categoria
  - Preço
  - Estoque
- Exibição de todos os produtos cadastrados

### 👤 Gestão de Clientes
- Cadastro de clientes com:
  - Nome
  - E-mail
  - Telefone
- Exibição de todos os clientes cadastrados

### 🛒 Registro de Vendas
- Registro de vendas com:
  - Cliente
  - Produto
  - Valor
  - Data da venda
- Exibição de todas as vendas realizadas

### 💰 Controle Financeiro
- Registro de transações financeiras com:
  - Tipo (Entrada ou Saída)
  - Descrição
  - Valor
  - Data
- Exibição de todas as transações financeiras

### 📈 Dashboard
- Exibição de métricas financeiras:
  - Total em vendas
  - Entradas financeiras
  - Saídas financeiras
  - Saldo atual

---

- **Python**
- **Streamlit** – Interface do usuário
- **Pandas** – Manipulação de dados
- 
- **Datetime** – Registro de datas e horários
